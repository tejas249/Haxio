# Resetting your API key

Go to **Settings > API Keys** in the dashboard. Click **Revoke** next to the
old key, then **Generate new key**. The old key stops working immediately,
so update any running integrations before you revoke it.

If you've lost access to the dashboard itself (locked out), contact support
and we can revoke a key on your behalf after verifying your account email.

API keys are scoped per account, not per user — any teammate with dashboard
access can see and rotate them.
